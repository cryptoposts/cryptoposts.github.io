Pending bridge deposit: speed up or cancel?

Speed up or cancel a pending bridge deposit in MetaMask? Learn when to replace a transaction, cancel it, or wait for the bridge to finish.

Crypto Bulletin Newsroom Nov 21, 2026 · 01:17 UTC 2 min read

Speed up a pending deposit you still want, cancel one you no longer want while it remains pending, and wait once Ethereum confirms it. This gives you a safe rule to share with the friend whose MetaMask is stuck.

Gnosis Bridge moves tokens and messages between Ethereum and Gnosis Chain, so the Ethereum transaction is only one part of the transfer. When comparing options for a bridge route, omnibridge vs xdai bridge can help put Gnosis Bridge in context.

Why is my bridge deposit still pending?

A deposit often waits because its max fee is below the current Ethereum base fee. In MetaMask, open the transaction and review its status; if it is still pending and the friend wants the transfer, speed it up with a higher fee.

An earlier pending transaction can also block the deposit. Ethereum orders a wallet’s transactions by nonce, so if an approval has a lower nonce than the deposit, the deposit cannot be mined first. Find the earlier pending transaction and speed that one up before changing the deposit.

Look up the transaction hash on Etherscan. A pending status means the Ethereum transaction has not been confirmed; a success status means it has, so track the transfer in Gnosis Bridge’s bridge history instead of trying to replace it.

Should I speed it up, cancel it, or wait?

Speed up the transaction if the friend still wants the transfer and Etherscan shows it pending. MetaMask resubmits it at the same nonce with a higher fee, which can help it get mined sooner.

Cancel only if the friend changed their mind and the transaction is still pending. MetaMask sends a 0 ETH self-transfer at the same nonce; it competes with the original transaction to replace it before either is mined. If the original confirms first, cancellation no longer applies.

Wait if Etherscan shows success. The Ethereum transaction is confirmed, so neither speed up nor cancel applies; follow the bridge transfer and contact the bridge’s support if its history does not reflect the confirmed transaction. Give them the transaction hash.

Tell your friend to check the lowest-nonce pending transaction first. That avoids speeding up a deposit while an earlier approval still holds the wallet’s transaction queue.
