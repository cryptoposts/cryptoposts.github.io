Why did my token approval confirm but not my restaking deposit?

Token approval confirmed but restaking deposit missing? Approval grants spending permission; a separate deposit transaction must succeed to record your stETH.

Crypto Bulletin Newsroom Nov 18, 2026 · 10:16 UTC 3 min read

A confirmed approval only lets the StrategyManager move your stETH; it does not record a restaking deposit. ERC-20 approval sets an allowance, and tokens move only when the spender calls transferFrom.

On eigen layer, an LST deposit uses a separate depositIntoStrategy transaction on the StrategyManager. The distinction is part of how eigen layer handles deposits and slashing, but the immediate check is whether that second transaction was sent.

The most common cause is that the second wallet prompt was closed, rejected, or never appeared. The approval can still confirm on-chain because it was a separate transaction; reopen the restaking app, connect the same wallet, and submit the deposit step.

If you did sign a deposit, look up your wallet on Etherscan and review its transactions. A pending deposit has not yet completed; a reverted one failed, so no restaked balance was recorded. Open the transaction to see its status and details before trying again.

For a missing or reverted deposit, return to the app and send the deposit again. If the allowance is still valid, you may not need another approval; the app should request one only if the available allowance is insufficient. The eigen layer deposit is the transaction that calls depositIntoStrategy and moves the tokens.

An approval left behind after you abandon the deposit is a live allowance to the StrategyManager for the amount approved. It does not itself move your stETH, but the spender remains authorized up to that allowance. Use Etherscan’s Token Approval Checker to review and revoke it if you are not proceeding.

Contact the restaking app’s support if Etherscan shows a successful deposit transaction but the app still shows no balance after it has confirmed. Include the transaction hash, wallet address, and selected strategy so support can check the on-chain record.

What else should you know about an approval-only transaction?

Do I need to approve again before retrying the deposit?

Not necessarily. Retry from the app; it can use an existing sufficient allowance or ask for a new approval if needed.

Why did my deposit transaction revert?

The transaction failed, so the deposit was not recorded. Etherscan shows its status and details; share the hash with the app’s support team if those details do not explain the failure.

Is an unused approval a security risk?

It leaves the StrategyManager authorized to spend tokens up to the allowance. Revoke it with Etherscan’s Token Approval Checker if you have stopped the deposit.

How long does a deposit take to appear in the app?

First confirm the deposit transaction on Etherscan. If it succeeded but the app still has no balance, contact the app’s support with the transaction hash.
