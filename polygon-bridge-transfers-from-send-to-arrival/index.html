Polygon Bridge Transfers: From Send to Arrival

A Polygon PoS bridge deposit locks tokens on Ethereum, mints a matching balance on Polygon, and completes after the source transaction is confirmed.

Crypto Bulletin Newsroom Sep 30, 2026 2 min read

A Polygon PoS bridge deposit moves tokens from Ethereum to Polygon by locking the source assets and minting an equal amount on the destination chain. For supported tokens, the Polygon Portal guides the transfer, while the source transaction and bridge processing determine when the balance arrives.

What happens when you send tokens?

The bridge locks the tokens on Ethereum and mints a matching amount of pegged tokens on Polygon PoS, according to Polygon’s description of its native bridge. To see how Polygon Bridge transfers work, read the guide to the steps and token movement. This is a transfer between networks, not a swap into a different asset.

Which steps take the transfer from send to arrival?

In the Portal, connect a wallet, choose Ethereum as the sending network and Polygon PoS as the destination, then select a supported token and amount. Check the destination address before confirming; the connected wallet address is generally the recipient unless you choose another address.

An ERC-20 token may need a separate approval transaction before the bridge can transfer it. Then sign the deposit transaction on Ethereum and pay its network fee in ETH. The wallet approval lets the bridge contract use the selected token amount; it does not itself move the tokens.

  • Confirm the token and amount on the Ethereum side.
  • Review the receiving address and destination network.
  • Approve the token if the wallet requests it, then submit the deposit.
  • Track the transaction in the Portal and check the Polygon wallet balance after processing.

Ethereum’s confirmation is only the first milestone. The bridge must process the deposit before the matching balance is available on Polygon, so a wallet’s “sent” notice does not by itself mean the transfer has arrived. Polygon does not give a fixed arrival time for every transfer; network conditions can affect the wait.

What should you check before using the tokens?

Check the destination wallet on Polygon PoS, rather than expecting the funds to appear on Ethereum or another Polygon network. If the token is supported and mapped, its Polygon representation corresponds to the Ethereum asset; token names and symbols can look alike, so verify the asset and network in the wallet.

Arrival and ability to spend are separate steps. Polygon PoS charges transaction fees in POL, so keep some POL in the destination wallet for later transfers or swaps. If the balance appears but transactions fail, check that the wallet is connected to Polygon PoS and has POL for gas.

The native bridge suits a direct transfer when the asset is supported and the recipient can wait for bridge processing. Its lock-and-mint model preserves the asset’s representation across the two networks; the practical trade-off is that the deposit depends on Ethereum confirmation and bridge processing before funds are usable on Polygon.
