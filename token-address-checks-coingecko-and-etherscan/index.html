Token Address Checks: CoinGecko and Etherscan

To verify a token contract, use project docs for the starting address, CoinGecko to match its chain, and Etherscan to inspect the deployed contract.

Crypto Bulletin Newsroom Nov 25, 2026 · 07:09 UTC 2 min read

Use the project’s own docs to identify a token address, CoinGecko to match it to the right chain, and Etherscan to inspect the deployed contract. Neither source is enough alone: CoinGecko is a curated index, while Etherscan records on-chain activity, and anyone can deploy a token using another project’s name or symbol.

For a Matcha swap, the address identifies the asset the decentralized exchange aggregator can route across liquidity sources. The same address check matters for matcha limit orders, because the contract identifies the token being traded.

Start with the chain you plan to use. A project’s token can have one address on Ethereum and different addresses on Arbitrum, Optimism or Polygon; CoinGecko lists contract addresses separately for each supported chain, so select the entry for your swap’s chain.

Pre-swap contract checks

  • Address from project docs: Copy the contract address published in the project’s own documentation or official site. Names and symbols are set by whoever deploys a contract, so they cannot identify the token on their own.
  • Matching CoinGecko entry on the same chain: Find the project’s coin page and compare its contract address for the chain you will use. If you are swapping on Arbitrum, use that chain’s address, not the Ethereum address at the top of a list.
  • Verified source on the explorer: Open the address on Etherscan for Ethereum or Arbiscan for Arbitrum. Etherscan’s “Contract Source Code Verified” label means the published source compiles to the deployed bytecode; it helps you inspect the contract, but does not establish that the project is trustworthy.
  • Contract age and holder count: Review the deployer, creation date, holders and transfer history on the explorer. A longer transaction history and broad holder spread give useful context; compare them with the project’s known activity rather than treating either as proof by itself.
  • Proxy and admin status: Look for “Read as Proxy” on Etherscan. It indicates an upgradeable token, and its admin can change the contract’s logic later, so check who controls that admin role before relying on the current behavior.

For a Matcha swap, the quick sequence is project docs, the matching CoinGecko entry, then the chain’s explorer. Treat any mismatch in address or chain as a reason to stop and recheck before trading.
