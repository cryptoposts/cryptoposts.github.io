How to verify Bitcoin arrived on Solana

A Bitcoin transfer is complete only when the bridge’s destination transaction credits the Solana token account with the right mint and amount and reaches finality.

Crypto Bulletin Newsroom Oct 16, 2026 · 02:51 UTC 2 min read

A Bitcoin transfer has arrived on Solana only when a successful destination transaction credits the intended Solana token account with the expected asset. A Bitcoin transaction alone proves the funds left the sending address; it does not prove that a Solana token was issued or delivered.

What does a Bitcoin transfer to Solana create?

It creates a token on Solana or another asset specified by the route, rather than moving native bitcoin onto Solana. The bridge may lock or custody BTC and issue a token representation, or route the value into a different asset; check the selected output before sending.

The bridge’s status page can connect the two sides of the transfer with separate transaction identifiers. For more detail on the route, the manta bridge guide walks through moving bitcoin into Solana; the checks here focus on confirming delivery onchain.

How do you check the Solana transaction?

Open the destination signature in a Solana explorer or query it through Solana’s RPC. Solana’s documentation describes transaction statuses as processed, confirmed and finalized; wait for finalized when you need the strongest confirmation the transaction has settled.

Check the transaction result and token balance change, not just a “complete” message from the bridge. Solana’s RPC documentation says a transaction lookup returns details such as its slot and execution metadata; a failed transaction or one that cannot be found does not confirm delivery.

  • Confirm the recipient is your Solana wallet or its associated token account.
  • Check the token’s mint address. A matching ticker or token name does not establish that it is the asset the bridge promised.
  • Compare the credited amount with the quoted output, accounting for the route’s stated fees or conversion.
  • Check that the destination transaction succeeded and reached finalized status.

What proves the bridge completed the transfer?

The strongest practical check is a successful, finalized Solana transaction showing the expected token arriving at the correct account under the correct mint. Match that record to the destination signature provided by the bridge; the Bitcoin-side transaction and the Solana-side transaction are separate records on separate networks.

If the Bitcoin transaction is visible but the Solana credit is missing, check the bridge’s transfer status and destination details before retrying. A pending bridge operation can take time to complete, while sending again could start a second transfer.
