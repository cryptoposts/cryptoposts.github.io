Check the wallet network before a bridge deposit

A wallet network mismatch can stop a bridge deposit or send funds along the wrong route; check the source chain, token and destination before signing any transaction.

Crypto Bulletin Newsroom Oct 15, 2026 · 05:19 UTC 3 min read

A wallet network mismatch can block a bridge deposit or send assets on a chain the recipient does not support. Before signing, match the wallet’s active network to the bridge’s source network, then check the token and destination shown in the transaction.

Why does a bridge deposit show the wrong network?

A bridge transaction starts on a source chain and aims to deliver assets on a destination chain. The connected wallet’s active network needs to match the selected source chain; the bridge may prompt you to switch networks before it can submit the deposit.

Wallets can show the same address on several EVM-compatible chains, but each chain keeps separate balances and transaction records. Sending to the same address on another chain does not move the asset there. A bridge coordinates that cross-chain move, sometimes alongside a token swap; how Relay Bridge combines cross-chain moves and swaps explains that single-flow approach.

What should I check before signing a bridge deposit?

Check the bridge’s transaction summary against the wallet prompt. The summary identifies the route and expected output; the wallet prompt is where you approve the on-chain action, so pause if the network, token, amount or destination differs.

  • Source network: Confirm the wallet is set to the chain holding the asset and that the bridge lists it as the source.
  • Token and amount: Confirm the asset contract or token name and amount. A token with the same ticker on two chains may be a different asset.
  • Destination: Check the receiving chain, address and expected token. A cross-chain swap can deliver a different token from the one you deposit.
  • Fees: Check the quoted fees and whether you have the source chain’s native token for gas. Some token deposits also require a separate approval transaction.

For an exchange deposit, use the exact network the exchange lists for that asset. A wallet address that looks familiar does not show which network the exchange will credit.

What if the deposit was sent on the wrong network?

First, check the transaction hash in the explorer for the network that processed it. If the funds went to an address you control on another EVM chain, switching the wallet to that chain may reveal them; moving them onward still requires a supported route and gas.

If the receiving address belongs to an exchange or service, contact its support with the transaction hash and network. Recovery depends on the recipient’s capabilities, and confirmed transactions generally cannot be reversed.
