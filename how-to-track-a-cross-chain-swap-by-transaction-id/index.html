How to Track a Cross-Chain Swap by Transaction ID

A cross-chain swap can have several transaction hashes. Follow the deposit, protocol processing and destination payout to locate a delay and check the right chain.

Crypto Bulletin Newsroom Oct 15, 2026 · 13:00 UTC 2 min read

Track a cross-chain swap by following its deposit transaction, the protocol’s processing record and the payout transaction on the destination chain. A transaction ID usually identifies one transaction on one network, so the deposit hash alone may not show whether the recipient has been paid.

For a THORChain swap, the THORChain Tracker accepts a swap transaction ID, while the source and destination chain explorers show their own transactions. The thor swap guide covers what to do when a swap stalls.

Which transaction ID should you start with?

Start with the hash for the asset leaving your wallet. Find it in the wallet’s activity or the swap interface’s transaction details, then open it in an explorer for that asset’s network.

Check that the transaction is confirmed and that its destination matches the swap’s deposit address. Save the full hash; shortened versions in wallet histories can be hard to search accurately.

How do you follow the swap across chains?

After the deposit confirms, look up the same hash in the protocol’s tracker or status page. THORChain’s tracker has a swap transaction ID search, and THORChain’s transaction status information can show stages such as observation, swap execution and outbound scheduling.

A cross-chain swap is not a single transaction copied between networks. The protocol observes the incoming transfer, processes the swap, then arranges a separate outgoing transaction on the destination network. Use each record to follow the movement:

  • Deposit: The source chain confirms the asset was sent to the swap’s deposit address.
  • Processing: The protocol record shows whether the deposit was observed and the swap processed.
  • Payout: The destination chain’s transaction hash shows whether the output reached the stated address.

THORChain’s guide to reading transactions describes settlement on the respective chains involved. That means a successful deposit is evidence of arrival, not proof that the destination payout has completed.

What does a pending status mean?

A pending status tells you which step has not finished; it does not by itself mean the funds are lost. If the deposit is confirmed but no payout hash appears, check the protocol tracker for its current stage before treating the swap as complete.

If a payout hash exists, open it in the destination chain’s explorer and verify its confirmation and recipient address. If the record remains unclear, share the full deposit hash with the swap service’s support team; never provide a seed phrase or private key.
