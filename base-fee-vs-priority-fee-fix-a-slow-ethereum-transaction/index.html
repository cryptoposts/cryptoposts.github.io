Base fee vs priority fee: fix a slow Ethereum transaction

Base fee vs priority fee: raise maxFeePerGas when it misses Ethereum’s base fee, or maxPriorityFeePerGas when the tip is too low to get included.

Crypto Bulletin Newsroom Nov 27, 2026 · 09:31 UTC 3 min read

Check the pending transaction’s fee fields against Ethereum’s current base fee first, because that tells you whether to raise maxFeePerGas or maxPriorityFeePerGas. The protocol sets the base fee, so you cannot raise it; raise maxFeePerGas if it is too low, and raise the priority fee if the max fee already covers the base fee but the transaction is still waiting.

With EIP-1559, maxFeePerGas is your total per-gas cap, while maxPriorityFeePerGas is the tip offered to the validator. Inclusion requires the max fee to cover the block’s base fee; once it does, a higher effective tip can help your transaction compete for space. The EIP-1559 specification says the base fee is burned and can change by at most 12.5% per block.

A maxFeePerGas below the current base fee leaves the transaction unincludable until the base fee falls or you replace the transaction with a higher cap. Compare your cap with the current base fee shown by your wallet or a fee tracker. When the cap is already high enough, a low maxPriorityFeePerGas can leave validators prioritizing transactions with better tips; raise the tip to compete.

To replace a pending Ethereum transaction, submit a new transaction from the same account with the same nonce and higher fees. Geth’s default price bump is 10%, and its transaction pool checks that both the replacement’s max fee and tip meet the bump; raising only one can trigger “replacement transaction underpriced.” The Geth transaction pool code shows that rule. Wallets and other node software may apply different replacement policies.

A slow deposit through Monad bridge, a cross-chain app for transferring supported assets between Monad and Ethereum, is still an Ethereum transaction while it waits on Ethereum. Use your wallet’s speed-up option to replace it with the same nonce and higher maxFeePerGas and maxPriorityFeePerGas; check that the new cap covers the current base fee and the new tip is competitive.

If neither fee explains the delay, check the transaction status and nonce in a block explorer. It may already be confirmed, dropped from a node’s pool, or waiting behind an earlier transaction from your account.

  • Max fee below base fee: raise maxFeePerGas.
  • Max fee covers base fee but inclusion is slow: raise maxPriorityFeePerGas.
  • For a replacement, reuse the nonce and bump both fee fields.

Other pending-transaction questions

How do I cancel a pending Ethereum transaction?

Submit a zero-value transaction to your own address using the pending transaction’s nonce and a higher fee. It competes to replace the original, so bump both fee fields enough for your wallet and node to accept it; cancellation is not guaranteed until the replacement is included.

What gas limit should a bridge transaction use?

Use the gas limit estimated by the wallet or bridge for that specific transaction. The gas limit sets the maximum execution gas available; raising it does not raise the priority fee or make a transaction with an insufficient maxFeePerGas includable.

Why does my wallet mark a transaction as dropped?

A wallet may mark a transaction dropped when it no longer sees it in the node’s pending pool. Check a block explorer and your account nonce: the transaction may have been replaced, expired from that node’s pool, or still be pending elsewhere.
