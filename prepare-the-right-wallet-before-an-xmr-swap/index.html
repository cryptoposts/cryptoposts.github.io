Prepare the right wallet before an XMR swap

Before an XMR swap, confirm which wallet must send or receive, create a fresh Monero subaddress for payouts, sync the wallet and protect its recovery seed.

Crypto Bulletin Newsroom Oct 3, 2026 2 min read

Before an XMR swap, identify which wallet sends the deposit and which wallet receives the output; the address you need depends on the direction of the trade. If XMR is the output, prepare a Monero wallet that you control and can access after the swap. Monero’s documentation explains that an XMR bridge handles the conversion between assets; the wallet still needs to receive the resulting XMR.

What wallet do you need for an XMR swap?

Use a wallet that supports the asset you will receive and that you can use to access or spend the funds. For an XMR payout, that means a Monero wallet with a receive address; for a swap that sends XMR out, it means a Monero wallet with spendable funds and the ability to approve the transaction. For more on the conversion step, read this explanation of what an XMR bridge does.

Which Monero address should you use?

Use a fresh subaddress from your wallet’s receive screen when you expect to receive XMR. Monero’s documentation recommends subaddresses for receiving: they let you use a separate address for each expected payment, while the funds remain in the same wallet. Copy the address from the wallet and check that the swap form asks for an XMR destination, not an address for the asset you are sending.

  • For XMR-to-XMR swaps, confirm which wallet sends and which receives.
  • For swaps into XMR, generate a receive subaddress in your Monero wallet.
  • For swaps out of XMR, check that your wallet can send and approve the requested amount.
  • Match the swap form’s asset and network labels to the address you provide.

What should you check before sending?

Make sure the Monero wallet has finished scanning and shows the funds you plan to spend; wallet software scans the blockchain to find transactions belonging to the wallet. Check the displayed amount, destination asset and address before confirming, since a correct XMR address cannot receive a different coin. If the swap will pay out XMR, keep the wallet available so you can check for the incoming transaction.

Keep your recovery seed offline and private. Monero’s wallet guidance says the seed can recover the wallet, while a wallet password protects the wallet file; neither belongs in a swap form or support chat. The practical preparation is simple: know which wallet is sending, create a fresh receive address if XMR is coming in, and verify the destination before approving the swap.
