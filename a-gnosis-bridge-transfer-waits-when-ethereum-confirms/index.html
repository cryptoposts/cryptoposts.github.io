A Gnosis Bridge Transfer Waits When Ethereum Confirms

A bridge transfer can stay pending after deposit confirmation because Ethereum inclusion starts the process; validators must relay the message and Gnosis Chain must execute it.

Crypto Bulletin Newsroom Nov 21, 2026 · 05:09 UTC 2 min read

Gnosis Bridge moves tokens and messages from Ethereum to Gnosis Chain, and a confirmed Ethereum deposit can still be pending because validators must relay its message before the destination contract executes it.

  • Ethereum confirmation records the source transaction; it does not complete delivery.
  • Bridge validators confirm the message until the required threshold is met.
  • The Arbitrary Message Bridge then executes it on Gnosis Chain.

Ethereum confirmation starts the bridge message

When an Ethereum deposit confirms, it emits a UserRequestForAffirmation message for bridge validators. That confirms the source action, while the cross-chain transfer still has relay and execution steps to finish.

When MetaMask still shows the Ethereum transaction as pending, the bridge process has not started; the relevant next step is speeding up or cancelling a Gnosis Bridge deposit. For a Gnosis Bridge transfer, use that remedy only before Ethereum confirms the deposit.

Say you deposit an ERC-20 token from Ethereum to Gnosis Chain through Omnibridge. Your Ethereum transaction confirms and emits the message, but the Gnosis Chain representation is not minted until the destination message executes.

Validators relay the message before destination execution

Bridge validators observe the message and submit confirmations. Once the required threshold is met, the Arbitrary Message Bridge executes the message on Gnosis Chain, triggering the mint of the token’s Gnosis Chain representation in this Omnibridge case.

These steps explain why a valid deposit can wait after Ethereum has confirmed it. Relayers affect liveness: if they stop, the message waits. They cannot change its message hash, so the wait concerns when the message moves, not its contents.

Open the bridge explorer and find the transfer by its source transaction or message. A status awaiting relay points to the validator step; a status awaiting execution means the message has passed relay and is waiting for the destination contract.

Use that status to decide what to do: wait while relay or execution is outstanding, and investigate the Ethereum transaction itself only if the wallet still shows it as pending.
