Why does my Base fee include an L1 data fee?

Why does my Base transaction fee include an L1 data fee? It pays for publishing compressed transaction data to Ethereum; size and Ethereum fees move the cost.

Crypto Bulletin Newsroom Nov 27, 2026 · 22:17 UTC 3 min read

A Base transaction includes an L1 data fee because Base publishes transaction data to Ethereum, and that fee is your share of the posting cost. It sits alongside the L2 execution fee: one pays to run the transaction on Base, the other helps pay to make its data available on Ethereum.

Say you send ETH to another wallet. The sequencer includes the signed transaction in a batch, compresses the batch, then posts it to Ethereum as blobs. Publishing that data costs money, and Base’s L1 fee calculation allocates a share of the cost to your transaction. That Ethereum data availability is what makes Base a rollup rather than a sidechain.

What changes the L1 data fee

The L1 data fee depends on transaction size and Ethereum’s fees, not just the gas used on Base. Since the Ecotone upgrade, the calculation uses Ethereum’s base fee and blob base fee, with scalars set for Base. The GasPriceOracle predeploy at 0x420000000000000000000000000000000000000F estimates the fee.

Now compare that send with a token swap routed through several pools. Holding L2 gas roughly equal, the multi-hop swap carries more transaction data; after compression, its larger byte size can mean several times the L1 fee of a plain ETH send. The execution fee can be similar in this comparison, while the L1 part rises with the compressed data size.

For a Base bridge withdrawal, the data fee covers the transaction’s share of posting cost; proving and finalizing an OP Stack withdrawal explains what must happen before the withdrawn funds can be claimed on Ethereum. The withdrawal process and the transaction’s L1 data fee answer different questions.

Ethereum blob demand also moves the fee. A quiet Base block does not hold the L1 part steady if blob space on Ethereum has become more expensive. Receipts and Basescan show the L2 execution fee and L1 data fee separately, so you can see which part changed.

Other questions about Base’s L1 data fee

Does the L1 data fee go to Ethereum validators or to Base?

The fee is charged as part of your transaction on Base; it is not a direct payment from your wallet to an Ethereum validator. Ethereum validators earn fees for including the batch’s blob on Ethereum.

Why did my fee change between estimate and confirmation?

The estimate and inclusion can use different Ethereum base fees, blob base fees, or Base scalars. The final transaction’s signed bytes can also change the size estimate used for the L1 fee.

Do other OP Stack chains charge the same L1 fee?

Other OP Stack chains also charge for publishing transaction data to Ethereum, but their fee parameters can differ. The exact L1 fee depends on each chain’s settings and the Ethereum fees in effect.
