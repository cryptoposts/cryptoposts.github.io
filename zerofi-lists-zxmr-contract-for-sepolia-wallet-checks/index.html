ZeroFi lists zXMR contract for Sepolia wallet checks

To verify zXMR on Sepolia, match its contract address and chain ID, inspect the explorer record, then import the address; a wallet label alone proves nothing.

Crypto Bulletin Newsroom Sep 30, 2026 2 min read

To verify zXMR in a Sepolia wallet, match its token contract address on chain ID 11155111 before importing it. ZeroFi’s bridge page lists the zXMR contract as 0x60B72Bb62ED83578F00D0C8F7a167c8C0B80Cd88 and gives 11155111 as the chain ID.

That address identifies the token contract on Sepolia; the ticker or name displayed by a wallet does not. The zerofi bridge guide covers the wider transfer process, while this check is about confirming the token shown in the wallet matches the contract.

Which zXMR contract should you check?

Use the full address published by ZeroFi, then compare it character for character with the address shown on the Sepolia explorer. A matching symbol is not enough: ERC-20 contracts can use the same ticker, and wallets may display token names supplied by the contract.

Open the contract address directly on Sepolia Etherscan or paste it into the explorer search field. Confirm that the page is for Sepolia and that its contract address matches ZeroFi’s listing; Etherscan’s contract page presents the address and on-chain activity, while its source-code verification status is a separate detail. A verified source can help readers inspect code, but Etherscan says source verification alone does not establish that a contract is safe.

How do you add zXMR to a Sepolia wallet?

Switch the wallet to Sepolia first, then add a custom token using the published contract address. MetaMask’s help centre says users can add unlisted EVM tokens by pasting the contract address into its custom-token flow; use the values the wallet reads from the contract when offered, rather than choosing a token solely by symbol.

  • Check the selected network is Sepolia, with chain ID 11155111.
  • Paste the full zXMR contract address listed by ZeroFi.
  • Review the token details the wallet reads, then import the token.
  • Compare the wallet balance with the token’s on-chain balance for your address.

Importing a token changes how the wallet displays an asset; it does not move funds or prove that a displayed balance came from a particular bridge transaction. To check a transfer, open its transaction hash on the Sepolia explorer and confirm the transaction succeeded, the token contract is zXMR’s listed address, and the recipient is your wallet address. The token’s transfer record and your address’s balance provide on-chain evidence; a token icon or name does not.

What does a zXMR check confirm?

A contract and network match confirms that the wallet is displaying the token at the address ZeroFi publishes for Sepolia. It does not, by itself, confirm that a bridge transfer completed or establish what backs the token; those questions require checking the transaction and the bridge’s stated process.

For most readers, the useful sequence is simple: verify the network, verify the full contract address, then check the transaction if you are tracing a deposit. If the contract address differs, do not treat a matching “zXMR” label as confirmation.
